# 2026-07-23 작업 기록

## 1. 프로젝트 이름 변경 (baby_recipe → reciplog)

### 1-1. 변경 배경

- 이유식 전용 앱에서, 일반 레시피까지 다 포함하는 범용 레시피 앱으로 확장하기로 함
- "baby_recipe"라는 이름이 더 이상 프로젝트 범위와 맞지 않아 개명 진행

### 1-2. 새 이름 후보 검토

- `recipe-hub` — 레시피를 모으는 허브라는 의미, 직관적
- `reciplog` (recipe + log) — 레시피 기록/피드 기능과 잘 맞고 독특해서 채택
- `cookiary` (cook + diary) — 좀 더 감성적인 톤
- 최종 선택: **reciplog**

### 1-3. 변경 범위 결정

- 옵션: (a) 표시용 이름만, (b) + Gradle 프로젝트명, (c) + Java 패키지명 전면 변경, (d) + 폴더명/GitHub 저장소명
- **이번엔 (d) 폴더명 + GitHub 저장소명만 변경**하기로 결정
  - Gradle `rootProject.name`(`baby-recipe`), Java 패키지명(`com.babyrecipe`)은 이번 범위에서 제외 → 추후 필요 시 별도 진행

### 1-4. 실제 변경 작업

- 백업 여부 검토: rename은 삭제가 아니고 GitHub이 구 URL을 자동 리다이렉트해줘서 위험도 낮다고 판단 → 별도 미러 백업은 생략하기로 결정
- `gh repo rename reciplog --repo f-lab-edu/baby_recipe` 실행 → GitHub 저장소가 `f-lab-edu/reciplog`로 변경됨
- `git remote set-url origin https://github.com/f-lab-edu/reciplog.git` 실행 → 로컬 remote URL 동기화
- `git fetch origin`으로 정상 동작 확인
