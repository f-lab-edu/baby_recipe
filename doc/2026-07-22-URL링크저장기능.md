# 2026-07-22 작업 기록

## 1. URL 추출 실패 시 "링크만 저장" 폴백 구조 추가

### 1-1. 배경
- 인스타그램처럼 크롤링 자체가 막힌 사이트는 `POST /api/recipes/extract`가 항상 하드 에러(`BabyRecipeException.badRequest`)로 끝나서, 사용자가 아무것도 저장하지 못하고 URL을 다시 입력해야 했음.
- 범위 결정: 크롤링 차단뿐 아니라 네트워크 오류/AI 파싱 실패 등 **모든 추출 실패**를 동일하게 "링크만 저장" 흐름으로 전환하기로 함 (사용자 선택 — 도메인별로 분기하지 않고 일관된 UX 우선).

### 1-2. 백엔드 구현 (What / Why)
- `Recipe`/`RecipeRequest`/`RecipeResponse`/`RecipeExtractResponse`에 `sourceUrl` 필드 추가. 성공/실패 관계없이 원본 링크를 항상 레시피에 붙여서 저장.
- `RecipeExtractService.extract(url)` 전체(fetch → Claude 호출 → 파싱)를 try/catch로 감싸, 실패 시 예외를 던지는 대신 `buildUrlOnlyFallback(url)`을 반환하도록 구조 변경. `RecipeExtractController`는 계약이 동일해 변경 없음(항상 200 + 리스트 응답 유지).
- 제목 보강: `fetchQuickTitle()`이 `facebookexternalhit` UA로 `og:title`을 먼저 시도(소셜 미리보기용 크롤러에는 메타를 열어주는 사이트가 많음). 그마저 실패하면 `extractPathId()`로 URL 마지막 경로 조각(게시물 코드)을 제목 뒤에 붙여 최소한 레시피끼리 구분되게 함.

### 1-3. 프론트엔드 구현 (What / Why)
- `frontend/src/utils/sourceLink.js` 신규 — `hostnameOf`/`sourceLabel`/`isLinkOnly` 공용 유틸(도메인별 라벨: 인스타그램/틱톡/유튜브/네이버블로그/웹페이지).
- `RecipeForm.jsx`: 추출 실패(링크 전용) 시 빨간 에러 대신 핑크 그라디언트 안내 배너 + "원본 링크 열기" 칩 표시. 다중 추출 목록에서도 링크 전용 카드를 점선 테두리로 구분.
- `RecipeCard.jsx`: 링크 전용 레시피는 🔗 썸네일 + "링크" 리본 배지.
- `RecipeDetail.jsx`: "원문 보러가기" 링크 카드 추가, 재료/조리법이 비어있고 작성자 본인일 때만 보이는 콘텐츠 보완 안내.

## 2. 로컬 실행 이슈 확인 (미해결)
- 로컬에서 `./gradlew bootRun` 시도 → `application-local.yml`이 없어 DataSource 설정 실패로 부팅 안 됨. 해당 파일은 `.gitignore` 대상이라 로컬 DB 접속 정보를 직접 만들어야 함. 이번 세션에서는 DB가 준비되지 않아 로컬 실행/실제 브라우저 테스트는 보류하고, 배포 서버 기준으로만 확인.

## 3. "다른 사용자와 채팅" 기능 설계 착수 (미완료)
- 플랜 모드로 백엔드/프론트 구조 조사 완료:
  - 백엔드: `spring-boot-starter-websocket`, Redis 등 실시간/메시징 의존성 전혀 없음(이 프로젝트 최초의 실시간 기능이 될 것). JWT 인증은 `UserDetails.username`에 userId를 담는 방식, 컨트롤러는 `@AuthenticationPrincipal UserDetails`에서 `Long.parseLong(username)`으로 추출하는 패턴 일관 사용. `Follow` 엔티티(팔로우 관계)는 이미 존재.
  - 프론트: STOMP/SockJS 클라이언트 라이브러리 없음. axios 인터셉터가 JWT를 `Authorization` 헤더에 부착하는 구조라 WebSocket 인증도 STOMP CONNECT 헤더로 동일하게 실어 보내는 방식이 자연스러움. `UserProfile.jsx`의 팔로우 버튼 옆에 "채팅하기" 버튼을 추가하기 좋은 위치 확인.
- 실시간 전송 방식(WebSocket/STOMP vs REST 폴링) 사용자 확인 질문을 올리려던 중 세션이 문서화 요청으로 전환되어 **미결정 상태로 보류**. 다음 세션에서 이어서 결정 필요.
