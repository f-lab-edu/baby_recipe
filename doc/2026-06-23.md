## 1. URL 추출 시 이미지 자동 스크래핑

### 문제
URL로 레시피를 추출할 때 텍스트만 Claude에 전달해서 대표 이미지·단계별 이미지가 항상 비어 있었음.

### 해결 방법 (`RecipeExtractService.java`)

**`PageContent` 레코드 추가**
```java
private record PageContent(String text, List<String> imageEntries) {}
```
텍스트와 이미지 목록을 함께 전달하는 내부 타입.

**`fetchContent()` 개선**
- `og:image` 를 첫 번째로 수집 (대표/완성본 이미지일 가능성이 높음)
- `<img>` 태그에서 lazy-load 속성(`src`, `data-src`, `data-lazy`, `data-lazy-src`, `data-original`) 순서로 URL 추출
- alt 텍스트가 없는 이미지는 부모·형제 DOM 텍스트를 최대 3단계까지 탐색하여 맥락 추출 (최대 80자)
- 수집한 이미지를 `[번호] URL (설명)` 형식의 목록으로 구성

**`fetchYouTubeMeta()` 개선**
- oembed 응답의 `thumbnail_url` 을 이미지 목록 첫 번째로 추가

**`callClaudeText()` 프롬프트 업데이트**
- 이미지 목록을 프롬프트에 포함
- JSON 스키마에 `imageUrl` (완성본), `steps[].imageUrl` (단계별) 필드 추가
- Claude가 목록에서 URL을 직접 선택하여 각 필드에 배정

## 2. EC2 재배포 시 환경변수 로드 문제 해결

### 문제
SSH 비대화형 세션에서 `source ~/.bashrc` 가 `/etc/bashrc` 의 인터랙티브 쉘 가드로 인해 무시됨
→ DB_HOST, DB_PASSWORD 등 환경변수가 설정되지 않아 앱 기동 실패

### 해결
`bash -l` (로그인 쉘) 옵션으로 `.bash_profile` → `.bashrc` 순서로 정상 로드

**재배포 명령어 (로컬 WSL에서):**
```bash
# 빌드
cd ~/test/baby_recipe
./gradlew clean build -x test

# EC2 전송
scp -i ~/test/babyrecipe-key.pem build/libs/baby-recipe-1.0.0.jar ec2-user@52.79.250.185:~/app.jar

# 재시작 (환경변수 포함)
ssh -i ~/test/babyrecipe-key.pem ec2-user@52.79.250.185 \
  "bash -l -c 'kill \$(ps -ef | grep java | grep -v grep | awk \"{print \\\$2}\") 2>/dev/null; sleep 1; nohup java -jar ~/app.jar --spring.profiles.active=prod > ~/app.log 2>&1 &'"
```
