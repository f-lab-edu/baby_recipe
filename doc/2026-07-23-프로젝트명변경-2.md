## 2. CD 배포 실패 및 수정

### 2-1. 문제 발생

- Gradle rootProject.name 변경 커밋(`b1b5e86`)을 push하자 "CD - Deploy to EC2" 워크플로우가 실패함
- 원인: `build.gradle`에 `archivesBaseName`이 별도로 없어 빌드 산출물명이 `rootProject.name`을 따라감
  - `baby-recipe-1.0.0.jar` → `reciplog-1.0.0.jar`로 바뀌었는데, `.github/workflows/cd.yml`의 scp 단계는 여전히 옛 파일명(`build/libs/baby-recipe-1.0.0.jar`)을 참조하고 있어 파일을 찾지 못해 배포 실패

### 2-2. 확인한 것

- 저장소 전체에서 `baby-recipe` / `baby_recipe` 문자열을 grep → doc/README 등 기록성 문서와 `frontend/package.json`의 `name` 필드(`baby-recipe-frontend`)만 남아있음을 확인
- `frontend/package.json`의 name 필드는 빌드 결과에 영향 없는 메타데이터라 이번 CD 실패와는 무관하다고 판단, 수정 범위에서 제외

### 2-3. 수정 작업
