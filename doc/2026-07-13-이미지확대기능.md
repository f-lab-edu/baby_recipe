## 1. 레시피 상세 이미지 클릭 시 확대(라이트박스) 기능 추가

### 1-1. 요구사항
- 레시피 상세 페이지에서 대표 이미지와 "만드는 법"의 각 단계 이미지를 클릭하면 화면에 크게 확대되어 보이도록 수정.

### 1-2. 구현 (What / Why)
- `RecipeDetail.jsx`에 `zoomImage` 상태를 추가하고, 대표 이미지(`recipe.imageUrl`)와 단계 이미지(`step.imageUrl`)에 `onClick={() => setZoomImage(url)}` 핸들러를 달았다.
- 확대 화면은 별도 라이브러리 없이 `position: fixed; inset: 0` 오버레이(라이트박스)로 직접 구현. 이유: 이미지 확대 하나 때문에 의존성을 늘릴 필요가 없고, 기존 코드 스타일(CSS Modules + 순수 React 상태)과 일관성을 유지하기 위함.
- 닫는 방법 3가지 제공: 배경 클릭, 우상단 ✕ 버튼, `Esc` 키.
  - `Esc` 처리는 `zoomImage`가 있을 때만 `keydown` 리스너를 등록하는 `useEffect`로 구현 (cleanup에서 해제).
  - 확대된 이미지 자체는 `e.stopPropagation()`으로 클릭해도 닫히지 않게 함.
- UX 디테일: 클릭 가능한 이미지에 `cursor: zoom-in`, 오버레이 배경에 `cursor: zoom-out` 적용.

### 1-3. 검증
- `npm run build` (vite) 정상 통과 → 빌드 결과물이 `src/main/resources/static/`에 갱신됨.
