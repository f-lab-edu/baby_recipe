## 오늘 한 것

### 환경 세팅 (앱 실행 준비)
- Docker로 MySQL 컨테이너(`mysql-babyfood`) 생성 완료
- `baby_recipe` DB 생성
- Maven 설치 (`sudo apt-get install -y maven`)

## 결정 사항

### Java 버전 설정
- `pom.xml`의 `java.version`을 **17로 유지**
- 원인: `maven-compiler-plugin 3.11.0` (Spring Boot 3.2.5 기본값)이 `--release 21` 미지원 (Java 21 출시 이전 버전)
- Java 21 JDK로 Java 17 타겟 컴파일은 정상 지원됨

### 앱 실행 방법
```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 mvn spring-boot:run
```
- 또는 `.bashrc`에 `export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64` 추가 후 `mvn spring-boot:run`
