## 1. URL 추출 대표 이미지 수정

### 문제
외부 이미지 URL을 브라우저에서 직접 로드 시 핫링크 차단 또는 CDN TTL 만료로 이미지 깨짐.

### 해결
**`ImageStorageService.saveFromUrl(String imageUrl, String pageUrl)`** 추가
- Claude가 선택한 외부 이미지 URL을 서버에서 직접 다운로드 → `/uploads/`에 저장 → 로컬 서버 URL로 교체
- `pageUrl`을 Referer 헤더로 전달 (네이버 CDN이 원본 페이지 Referer 요구)
- 다운로드 실패 시 원본 URL 유지 (null 대입 X)

**`RecipeExtractService.downloadExternalImages(response, pageUrl)`** 추가
- 대표 이미지 + 단계별 이미지 전부 서버 URL로 교체

## 2. URL 추출 단계 이미지 수정 (네이버 블로그)

### 문제 원인 분석
- 네이버 블로그 본문 이미지는 JavaScript로 동적 로드 → Jsoup 정적 파싱으로 수집 불가
- 수집된 이미지들이 `?type=w80_blur` (로딩 placeholder) → Claude가 매핑 불가
- 이미지 수집 최대 개수 15장 → 단계 많은 레시피에서 부족

### 해결

**모바일 URL로 변환 (`toMobileUrl`)**
```
blog.naver.com → m.blog.naver.com
```
모바일 버전이 더 단순한 HTML 구조로 SE 모듈 선택자로 접근 가능.

**이미지 품질 업그레이드 (`upgradeNaverImageQuality`)**
```
?type=w80_blur, ?type=w2 → ?type=w966
```
placeholder blur 이미지를 원본에 가까운 고화질로 교체.

**중복 제거 개선**
- URL 전체 비교 → base URL 비교(쿼리 파라미터 제외)로 변경해 og:image 중복 정확히 제거.

**텍스트-이미지 순서 구조화 (`buildNaverStructuredContent`)**
```
T:채소는 잘게 다지기
I[1]:https://...
T:토마토 껍질 제거 후 다지기
I[2]:https://...
```
블로그의 `.se-module-text` / `.se-module-image` 모듈을 순서대로 읽어 Claude에 전달.
→ Claude가 각 단계 설명과 인접한 이미지를 직접 매핑.

**이미지 수집 한도 확대**: 15장 → 30장

## 3. GitHub Actions CD 구축

### 구성
- 트리거: `main` 브랜치 push
- 빌드: Node.js(프론트엔드 Vite 빌드) → Java 17(Gradle 빌드)
- 보안 그룹 자동 IP 관리:
  - 배포 전 GitHub Actions runner IP를 EC2 보안 그룹에 추가
  - 배포 후 `if: always()`로 무조건 IP 삭제

### GitHub Secrets
| 이름 | 설명 |
|---|---|
| `EC2_HOST` | EC2 퍼블릭 IP |
| `EC2_USERNAME` | `ec2-user` |
| `EC2_KEY` | PEM 키 파일 내용 |
| `AWS_ACCESS_KEY_ID` | IAM 액세스 키 |
| `AWS_SECRET_ACCESS_KEY` | IAM 시크릿 키 |
| `EC2_SG_ID` | 보안 그룹 ID (`sg-xxxx`) |

### IAM 정책 (`github-actions-sg-only`)
```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "ec2:AuthorizeSecurityGroupIngress",
      "ec2:RevokeSecurityGroupIngress",
      "ec2:DescribeSecurityGroups"
    ],
    "Resource": "*"
  }]
}
```

### 앱 재시작 포트 충돌 수정
- `kill` (SIGTERM) → `kill -9` (SIGKILL) + `sleep 3`
- graceful shutdown 지연으로 8080 포트 점유 유지되는 문제 해결
