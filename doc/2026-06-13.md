## ✅ 완료 작업

### 1. RDS (MySQL) 생성

- 엔진: MySQL 8.0
- 템플릿: 프리 티어
- 인스턴스 식별자: `babyrecipe-db`
- 마스터 사용자: `admin`
- 퍼블릭 액세스: 아니요 (EC2에서만 접근 가능)
- VPC: 기본 VPC (EC2와 동일)
- 스토리지 자동 조정: 끔 (과금 방지)
- 초기 DB 이름: `babyrecipe`

**생성 후 보안 그룹 설정:**
- RDS 보안 그룹(`babyrecipe-rds-sg`) 인바운드 규칙 추가
  - 유형: MySQL/Aurora / 포트: 3306 / 소스: EC2 보안 그룹 ID (`sg-xxxx`)
  - ⚠️ 기존 규칙 수정 X → "규칙 추가" 버튼으로 새 행 추가

**EC2에서 DB 접속 및 스키마 생성:**
```bash
sudo dnf install -y mariadb105
mysql -h <RDS엔드포인트> -u admin -p
```
```sql
CREATE DATABASE babyrecipe CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2. Spring 프로파일 분리 (local / prod)

로컬과 AWS RDS를 동시에 지원하는 구조로 변경.

**파일 구조:**
```
src/main/resources/
├── application.yml          # 공통 설정 (기본 프로파일: local)
├── application-local.yml    # 로컬 DB (localhost)
└── application-prod.yml     # AWS RDS (환경변수 기반)
```

**application.yml** (공통):
```yaml
spring:
  profiles:
    default: local
  # DB 설정 제거, JPA/multipart/jwt 등 공통 설정만 유지
```

**application-local.yml:**
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/baby_recipe?useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8
    username: ${DB_USERNAME:root}
    password: ${DB_PASSWORD:password}
    driver-class-name: com.mysql.cj.jdbc.Driver
```

**application-prod.yml:**
```yaml
spring:
  datasource:
    url: jdbc:mysql://${DB_HOST}:3306/babyrecipe?useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    driver-class-name: com.mysql.cj.jdbc.Driver
```

**실행 방법:**
- 로컬: `./gradlew bootRun` (default: local 프로파일 자동 적용)
- EC2: `java -jar app.jar --spring.profiles.active=prod`

### 3. SpaController 버그 수정

**증상:** 브라우저에서 JS/CSS 파일이 `text/html` MIME 타입으로 반환됨

**원인:** `SpaController` regex가 `/assets/**` 경로를 잡아서 `index.html` 을 반환

```java
// 수정 전
@RequestMapping(value = {"/{path:^(?!uploads$)[^\\.]*$}", "/{path:^(?!uploads$)[^\\.]*$}/**"})

// 수정 후
@RequestMapping(value = {"/{path:^(?!uploads$|assets$)[^\\.]*$}", "/{path:^(?!uploads$|assets$)[^\\.]*$}/**"})
```

### 4. 앱 빌드 및 EC2 배포

**로컬에서 빌드:**
```bash
cd ~/test/baby_recipe
./gradlew clean build -x test
```
결과물: `build/libs/baby-recipe-1.0.0.jar`

**EC2로 전송:**
```bash
scp -i ~/babyrecipe-key.pem build/libs/baby-recipe-1.0.0.jar ec2-user@<EC2_PUBLIC_IP>:~/app.jar
```

**EC2 접속:**
```bash
ssh -i ~/babyrecipe-key.pem ec2-user@<EC2_PUBLIC_IP>
```

### 5. 환경변수 설정 및 앱 실행

**~/.bashrc에 저장 (SSH 재접속 후에도 유지):**
```bash
vi ~/.bashrc
```
아래 내용 맨 아래에 추가:
```bash
export DB_HOST=<RDS엔드포인트>
export DB_USERNAME=admin
export DB_PASSWORD=<비밀번호>
export JWT_SECRET=babyrecipe-secret-key-must-be-at-least-256-bits-long-for-hs256
export ANTHROPIC_API_KEY=sk-ant-...
```
적용:
```bash
source ~/.bashrc
```

**앱 실행:**
```bash
nohup java -jar app.jar --spring.profiles.active=prod > app.log 2>&1 &
```
