## 1. 프론트엔드 정적 파일 서빙 설정

- 증상: `http://localhost:8080/` 접근 시 403 오류

- 해결:

  - `SpaController` 신규 생성: React Router 경로에서 새로고침 시 `index.html`로 포워딩
  - `.gitignore`: `src/main/resources/static/` 빌드 산출물 제외 추가

## 4. AI 레시피 추출 오류 수정 (이슈 #2)

### 4-1. JWT 토큰 오류 (Found: 0 periods)
- 증상: 서버 로그에 `Invalid compact JWT string: Found: 0`
- 원인: 브라우저 localStorage에 저장된 토큰이 JWT 형식이 아님 (이전 세션 잔여 데이터)
- 해결: 개발자 도구 → Application → Local Storage → Clear 후 재로그인

### 4-2. Spring Security 인증 실패 응답 401로 변경
- 원인: 미인증 요청에 403 반환 → axios 인터셉터가 감지 못해 토큰 자동 갱신 불가
- 해결: `SecurityConfig`에 `AuthenticationEntryPoint` 추가 → 401 반환

### 4-3. Claude 배열 응답 파싱 실패
- 증상: `레시피 정보를 추출할 수 없습니다.` 오류
- 원인: Claude가 JSON 배열 `[{...}]`로 응답 → `RecipeExtractResponse` 객체로 파싱 실패
- 해결:
  - `parseResult()`: 배열 감지 시 첫 번째 요소 추출
  - 프롬프트에 "단일 JSON 객체 응답, 배열 금지" 명시

### 4-4. Request DTO @Setter 누락 (비밀번호 변경 무효 버그)
- 증상: 비밀번호 변경 시 성공 응답이 오지만 실제로 변경되지 않음
- 원인: `@Getter`만 있고 `@Setter`가 없어 Jackson이 모든 필드를 null로 역직렬화
  - `currentPassword`, `newPassword`가 null → 비밀번호 변경 블록 실행 안 됨
- 해결: 모든 Request DTO에 `@Setter` 일괄 추가
  - `UpdateProfileRequest`, `LoginRequest`, `RegisterRequest`, `RecipeRequest`, `CommentRequest`, `RecipeExtractRequest`

### 4-5. 로그 파일 및 DEBUG 로그 추가
- `application.yml`: `logging.file.name: logs/app.log` 추가
- `RecipeExtractService`: 추출 시작/Claude 응답 내용 DEBUG 로그 추가
