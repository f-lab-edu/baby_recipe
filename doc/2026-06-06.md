## 3. localhost:8080 접근 오류

- 증상: 브라우저에서 `http://localhost:8080/` 접근 시 오류
- 원인: Spring Security 설정상 `/` 루트는 인증 필요 경로 (`anyRequest().authenticated()`)
- 해결: 인증 없이 접근 가능한 경로 사용
  - `GET /api/recipes/**`
  - `POST /api/auth/**` (로그인, 회원가입)

## 4. 레시피 추가 기능 미노출 문제

- 증상: 프론트엔드에서 레시피 추가 메뉴가 보이지 않음
- 원인: Navbar에서 `isLoggedIn` 조건으로 로그인 시에만 "레시피 작성" 메뉴 노출
- 해결: 로그인 후 상단 네비에서 "레시피 작성" 메뉴 이용

## 5. URL 레시피 추출 - ANTHROPIC_API_KEY 미설정 오류

- 증상: `ANTHROPIC_API_KEY 환경변수가 설정되지 않았습니다.`
- 해결: 환경변수를 포함하여 서버 재실행
  ```bash
  ANTHROPIC_API_KEY="sk-ant-api03-..." ./gradlew bootRun
  ```

## 6. URL 레시피 추출 - API 키 인증 오류 (401)

- 증상: `Claude API 오류: 401 invalid x-api-key`
- 원인: API 키 오타 또는 불완전한 복사
- 해결: [console.anthropic.com](https://console.anthropic.com) 에서 새 키 발급 후 재입력
  - 키는 생성 직후에만 전체 확인 가능

## 7. URL 레시피 추출 - 인스타그램 파싱 실패

- 증상: `레시피 정보를 추출할 수 없습니다.`
- 원인: 인스타그램은 크롤링 차단 → Jsoup으로 내용을 가져올 수 없음
- 현재 지원 URL: 일반 레시피 블로그(네이버, 티스토리), 유튜브
- 인스타그램 지원은 로그인 세션 또는 별도 API 필요
