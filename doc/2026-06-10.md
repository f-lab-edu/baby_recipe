# 2026-06-10 작업 기록

## 1. 사진으로 레시피 등록 기능 추가 (이슈 #3)

### 1-1. 이미지 업로드 서비스 구현

- `ImageStorageService` 신규 생성
  - UUID 기반 파일명으로 `uploads/` 디렉토리에 저장
  - 허용 형식: jpg, png, webp / 최대 크기: 10MB
  - `save()`: 파일 저장 후 `http://localhost:8080/uploads/{uuid}.{ext}` URL 반환
  - `delete()`: URL에서 파일명 추출 후 실제 파일 삭제
- `WebMvcConfig` 신규 생성
  - `/uploads/**` 경로를 로컬 `uploads/` 디렉토리에 매핑 (정적 파일 서빙)
- `SecurityConfig`: `/uploads/**` permitAll 추가 (인증 없이 이미지 접근 가능)
- `application.yml`: `app.upload-dir`, `app.base-url` 설정 추가

### 1-2. 이미지 업로드 API

- `ImageUploadController` 신규 생성
  - `POST /api/upload` — 이미지 1장 업로드, `{ imageUrl }` 반환

### 1-3. Claude Vision API 연동 (사진으로 레시피 추출)

- `RecipeExtractController`: `POST /api/recipes/extract/images` 엔드포인트 추가
- `RecipeExtractService` 대폭 수정
  - `extractFromImages(List<MultipartFile>)`: 이미지를 base64로 인코딩해 Claude Vision 요청
  - `callClaudeVision()`: 텍스트 + 이미지 혼합 content block 구성
  - `parseVisionResult()`: `finishedImageIndex` → `imageUrl`, `stepImageIndex` → `step.imageUrl` 매핑
  - `finishedImageIndex` 없을 경우 첫 번째 이미지를 대표 이미지로 fallback
  - `repairJson()`: Claude 응답에서 배열 요소 간 쉼표 누락 자동 복구
  - 내부 클래스: `ClaudeMessage`, `ContentBlock`, `ImageSource` 추가
- `RecipeExtractResponse.StepItem`: `imageUrl` 필드 추가

### 1-4. 레시피 저장 버그 수정

- `RecipeRequest`: `imageUrl` 필드 누락으로 프론트에서 보낸 대표 이미지가 DB에 저장 안 되던 문제 수정
- `RecipeService.createRecipe()`: `.imageUrl(request.getImageUrl())` 빌더에 추가
- `RecipeService.updateRecipe()`: `imageUrl` 업데이트 반영
- `RecipeService.deleteRecipe()`: 레시피 삭제 전 연결된 대표 이미지 + 단계별 이미지 파일 모두 삭제

### 1-5. SpaController 라우팅 버그 수정

- 증상: `/uploads/uuid.png` 접근 시 이미지 대신 HTML(index.html) 반환
- 원인: SPA 패턴 `/{path:[^\\.]*}/**`이 `uploads` 경로도 가로챔 (점 없는 경로 전체 매칭)
- 해결: 네거티브 룩어헤드로 `uploads` 세그먼트 제외
  ```
  /{path:^(?!uploads$)[^\\.]*$}/**
  ```

## 2. 레시피 폼 UI 개선

### 2-1. 대표 이미지 업로드

- 기본 정보 섹션 최상단에 대표 이미지 업로드 필드 배치
- `ImageUploadInput` 컴포넌트 추가
  - 이미지 미리보기, 클릭 시 이미지 교체, ✕ 버튼으로 제거
  - 업로드 중 오버레이 표시
- AI 추출 결과의 `imageUrl`이 수동 업로드를 덮어쓰지 않도록 우선순위 처리
  ```js
  imageUrl: f.imageUrl || data.imageUrl  // 수동 업로드 우선
  ```

### 2-2. 단계별 이미지 업로드

- 만드는 법 각 단계에 `ImageUploadInput` 추가 (선택 사항)
- `RecipeRequest.StepItem`: `imageUrl` 필드 반영

### 2-3. AI 자동 추출 탭 UI

- "URL로 추출" / "사진으로 추출" 탭 전환 구조 (`AutoExtractor` 컴포넌트)
- `ImageExtractor` 컴포넌트: 최대 10장 다중 선택, 미리보기 그리드 표시

## 3. 레시피 상세 페이지 개선
