### 1-1. Stop 훅 설정 (`.claude/settings.json`)

- 세션 종료 시 자동으로 `daily_question.sh`가 실행되도록 Stop 훅 등록
- 매 대화 종료마다 오늘의 학습 질문 + doc 미저장 경고 표시

```json

    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "bash /home/jy_sm/test/baby_recipe/.claude/study/daily_question.sh"
          }
        ]
      }
    ]
  }
}
```

### 1-2. 오늘의 질문 스크립트 (`.claude/study/daily_question.sh`)

- `questions.json`에서 날짜(day of year) 기반으로 오늘의 질문 자동 선택 (총 28개 순환)
- 카테고리, 힌트, 관련 파일 경로 함께 출력
- 오늘 doc 파일이 없으면 하루에 한 번만 종료 알림 표시 (`.doc_reminded_YYYY-MM-DD` 플래그 파일로 중복 방지)

### 1-3. 대화형 퀴즈 루프 (`.claude/study/loop_prompt.md`)

- `/loop 퀴즈` 명령으로 대화형 퀴즈 세션 시작
- `loop_state.json`의 `current_index`로 진행 위치 추적 (현재 index: 2)
- 기능:
  - '힌트' 입력 시 힌트 제공
  - '건너뛰기' 입력 시 다음 문제로
  - '처음부터' 입력 시 index 0 리셋
  - '그만' / 'stop' 입력 시 루프 종료
- 정답 평가는 너그럽게 — 핵심 개념 언급 시 정답 인정

### 1-4. 세션 종료 자동 저장 규칙 (`claude.md`)

- 트리거 단어: `대화 종료`, `오늘 여기까지`, `마칠게`, `끝낼게`, `종료할게`
- 트리거 감지 시 즉시 `doc/YYYY-MM-DD-[주제].md` 형식으로 작업 기록 저장
- 파일명 주제는 한국어 2~3단어 붙여쓰기
