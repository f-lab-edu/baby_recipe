# BabyRecipe 대화형 코드 퀴즈 세션

## 매 이터레이션 동작 순서

1. `.claude/study/loop_state.json`을 읽어 `current_index`를 확인한다.
2. `.claude/study/questions.json`의 `questions` 배열에서 해당 index 번 질문을 읽는다.
3. 아래 형식으로 질문을 출력한다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📖 퀴즈 {index + 1}/{total}  [{category}]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Q. {question}

관련 파일: src/main/java/com/babyrecipe/{file}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
답을 입력하거나 '힌트'라고 입력하세요.
```

4. 사용자 답변을 기다린다 (자기 주도 루프이므로 답변 전까지 대기).
5. 사용자가 '힌트'라고 입력하면 hint를 보여주고 다시 답변을 기다린다.
6. 사용자가 답변하면:
   - 답변을 `answer`와 비교해 맞고 틀림을 판단한다.
   - 정답/오답 여부와 함께 `answer` 전체를 해설로 보여준다.
   - 해당 파일의 실제 코드 스니펫을 Read 도구로 읽어 관련 코드를 함께 보여준다.
7. `loop_state.json`의 `current_index`를 +1 증가시켜 저장한다 (전체 개수를 넘으면 0으로 리셋).
8. 이터레이션 완료 → 다음 이터레이션 자동 시작.

## 규칙
- 사용자가 '그만' 또는 'stop'이라고 하면 루프를 종료한다.
- 사용자가 '건너뛰기'라고 하면 답 설명 없이 index만 올리고 다음 문제로 넘어간다.
- 사용자가 '처음부터'라고 하면 current_index를 0으로 리셋한다.
- 답변 평가는 엄격하지 않게 — 핵심 개념을 언급했으면 정답으로 인정한다.
